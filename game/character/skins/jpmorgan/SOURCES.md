# JPMorgan artwork source

`jpmorgan_logo_white.svg` uses the J.P. Morgan wordmark paths from the official
[J.P. Morgan logo asset](https://www.jpmorgan.com/content/dam/logos-global/logo-jpm-brown.svg),
retrieved 2026-10-17. The fill was changed from brown to white and the SVG render
size increased; the wordmark paths are unchanged. The logo belongs to JPMorgan
Chase & Co. and is not original project artwork. The source is listed in the
[J.P. Morgan media centre](https://www.jpmorgan.com/contact-us/media).
